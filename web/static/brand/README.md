# Official partner logos (place the files here)

RESOLVE cannot download partner logos on its own. Put the **official** files in this folder with these exact names:

| File | Source to download from | Used for |
|---|---|---|
| `wispr-flow-logo.svg` (or `.png`) | Wispr Flow media kit: https://wisprflow.ai/media-kit | Intro, challenge section |
| `wemakedevs-logo.svg` (or `.png`) | WeMakeDevs official website: https://www.wemakedevs.org/ | Intro, challenge section |

Rules: use the artwork unchanged (no recolouring, distortion or effects). Record the source URL and the date you downloaded each file in `docs/BRAND_ASSETS.md`.

Until a file is present, the page shows the partner's **name as plain text** instead of a logo. It never substitutes a drawn or AI-made imitation.
